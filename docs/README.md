## Documentation Philosophy

Our documentation follows these principles:

1. **Show, don't just tell** - Examples over abstract explanations
2. **Practical over comprehensive** - Focus on what you'll actually use
3. **Concise and scannable** - Respect your time
4. **Real-world scenarios** - Based on actual usage patterns
