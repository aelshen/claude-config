# Contributing to AE Claude Code Setup

Thanks for your interest in improving this setup! This is a personal configuration shared publicly, but contributions are welcome.

## Philosophy

This setup prioritizes:
- **Pragmatism over perfection** - Favor working solutions
- **Simplicity over complexity** - Avoid over-engineering
- **Reality over claims** - Verify things actually work
- **Speed over ceremony** - Keep workflows efficient

## Types of Contributions

### 1. Bug Reports

If something doesn't work as documented:

- Describe what you expected
- Describe what actually happened
- Include relevant configuration
- Share your Claude Code version

### 2. Documentation Improvements

- Fix typos or unclear explanations
- Add examples that helped you
- Improve getting started guides
- Clarify agent usage patterns

### 3. New Examples

Share real-world usage examples showing:

- The problem you faced
- How you used the agents
- What the agents found/recommended
- The outcome

Examples help others understand practical usage.

### 4. Workflow Enhancements

Suggest improvements to:

- Agent coordination patterns
- Decision trees for agent selection
- Best practices based on your experience

## What NOT to Contribute

- Scale AI plugin content (this repo is plugin-agnostic)
- Complex abstractions or over-engineered solutions
- Features that add ceremony without clear value
- Changes that contradict the core philosophy

## How to Contribute

### Small Changes (Typos, Docs)

1. Fork the repository
2. Make your changes
3. Submit a pull request
4. Describe what you changed and why

### Larger Changes (New Sections, Examples)

1. Open an issue first to discuss
2. Get feedback on the approach
3. Implement the changes
4. Submit a pull request

## Style Guidelines

### Documentation

- Be concise and direct
- Use bullet points for clarity
- Include concrete examples
- Show before/after when relevant
- Focus on practical usage

### Examples

- Start with a real scenario
- Show step-by-step workflow
- Include actual agent output
- Explain key insights
- Show time/value tradeoffs

### Code Samples

- Keep it simple
- Comment only what's not obvious
- Show the problem before the solution
- Demonstrate the agent's value

## Review Process

- I'll review PRs as time permits
- Focus is on alignment with philosophy
- Preference for practical improvements
- Documentation improvements are easiest to accept

## Questions?

Open an issue or reach out. This is a community resource, and feedback helps everyone.
